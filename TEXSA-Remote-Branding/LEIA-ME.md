# TEXSA Remote — pacote inicial de identidade visual

Branch destinada: `texsa-branding` do repositório `eduwx/texsa-remote`.

Este pacote inclui somente recursos gráficos; **não contém executável nem altera código**.

- `branding/texsa-logo-original.svg` e `.png`: originais fornecidos.
- `branding/texsa-logo.png`: versão horizontal para interface.
- `branding/texsa-icon-1024.png`: ícone quadrado, composto usando a letra T da marca e fundo grafite.
- `res/icon.ico`: ícone Windows usado no processo de empacotamento do RustDesk.
- `flutter/windows/runner/resources/app_icon.ico`: ícone do executável Flutter Windows.
- `flutter/assets/icon.ico`: recurso do aplicativo.
- `res/tray-icon.ico`: versão provisória para bandeja do sistema.
- `res/icon.png`, `res/{32x32,64x64,128x128,256x256}.png`: recursos raster.

Copie os arquivos para os caminhos correspondentes no fork (não substitua pastas inteiras).
Outros recursos visuais e textos ainda precisam ser identificados e alterados em etapas posteriores.
A compilação e assinatura ainda não foram realizadas.
